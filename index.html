📋 Sources & Methodology

· Yahoo Finance — stock prices, SET index, Brent crude, US 10Y yield, USD/THB rate (15-min delayed per exchange policy)
· Google News RSS (TH) — live headlines, buzz-score input (hl=th, gl=TH)
· SET.or.th — official exchange data reference
· Pantip Sinthorn Room — retail discussion reference
Prices: Sourced from Yahoo Finance via a Netlify serverless function. Data is subject to a 15-minute exchange-mandated delay. Not suitable for live trading decisions — use SET.or.th or your broker for real-time quotes.

Buzz score: Counts English ticker + company-name mentions across 3 Thai-language Google News RSS pools (hl=th, gl=TH, 7-day window), weighted by recency (≤24h ×3, ≤72h ×2, older ×1), normalised 0–100. Both Thai and offshore stocks are scored from the same Thai-investor news pool, so buzz reflects Thai-investor discussion volume — not a global post count.

Dynamic ranking & discovery: Cards are rendered live and ranked by buzz; the displayed tickers change as discussion shifts. A discovery layer also scans headlines for uppercase ticker tokens NOT in the curated watchlist, resolves a live price for them (best-effort), and surfaces them as “Discovered” cards — so stocks not on the page can appear when Thai investors start talking about them.

Strategies: Rules-based, generated from the live top-buzz tickers and Yahoo price data — they reference whatever is trending this period, not a fixed ticker list. Editorial judgment is required before acting on any recommendation.

This dashboard is not investment advice. All data should be independently verified before use in client-facing materials.
